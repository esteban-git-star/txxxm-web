2 · Windows-App

Für Windows herunterladen
  1. Button tippen – Download startet (Google Drive).
  2. TivimPlayer_1.0.exe öffnen und installieren.
  3. Mit deinen Tivim-Daten einloggen.
Blauer Windows-Hinweis?

Normal bei neuer App: Weitere Informationen → Trotzdem ausführen.

2 · Purple Player einrichten

Im Mac App Store öffnen
  1. App installieren und öffnen.
  2. Consent → Sprache German → akzeptieren → überspringen.
  3. Neue Playlist hinzufügen → ganz unten Mit Code anmelden.
  4. Code eingeben: FA69EV
  5. Tivim-Benutzername & Passwort → Absenden → Load.
Wiedergabefehler?

Deinen Ansprechpartner schreiben – mit Benutzernamen, damit der Account freigeschaltet werden kann.
